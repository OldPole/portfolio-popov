# Страницы и интерфейс — 9 ноября 2026

Ветка: `2026-11-09.portfolio-pages`. Деплой и слияние в main не выполняются.

## Изменения

- Навигация ведёт на отдельные страницы опыта, проектов и контактов. У всех общие Header и Footer; EN/RU-переключатель сохраняет раздел.
- Страница опыта включает навыки, образование и скачивание CV. В описаниях Yandex, Aligned Hearts и Innowise раскрыты обязанности из CV. Стек Yandex уточнён по списку владельца.
- Удалены ссылка «A little more about me», блок «My approach» и нижняя строка футера с copyright, технологиями сайта и переключателем анимаций. Системная настройка reduced motion продолжает учитываться.
- В hero и футере добавлен Telegram `@OldPoleh`. Фото и три проекта со скриншотами сохранены.
- `UiButton` объединяет кнопки действий, внутренние ссылки-кнопки, внешние ссылки и иконки. Общие стили задают hover, focus-visible, active, disabled и курсор.
- Prettier форматирует Vue с одним атрибутом на строку и читаемыми границами тегов. ESLint проверяет качество кода, `eslint-config-prettier` устраняет конфликт правил. Настройки редактора заданы в `.editorconfig`.
- CI дополнен проверками линтера и форматирования. Автотесты не добавлены.

## Проверки

- `npm run lint`, `npm run typecheck`, `npm run format:check`, `npm run build` — успешно.
- Все 14 языковых URL отвечают HTTP 200 и содержат один H1, шапку и футер. CV доступен и имеет корректную PDF-сигнатуру.
- Sitemap разобран XML-парсером на временном локальном сервере с зарезервированным тестовым доменом: 14 уникальных адресов.
- В браузере проверены переходы между страницами, смена темы, переключение языка, hover-фон переключателей, cursor pointer и закрытие мобильного меню после выбора ссылки. На ширине 390 px не обнаружено горизонтальной прокрутки.
- На странице SeriesPoisk загружается скриншот; ссылки назад и на контакты ведут на отдельные страницы. В консоли приложения не обнаружено ошибок и предупреждений.
